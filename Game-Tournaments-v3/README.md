# Game-Tournaments-v3

A lightweight, iPad-friendly tournament website you can run from a single folder.

## What it does

- Add player names.
- Add games and rules for each game.
- Edit per-game scores live.
- Run a slideshow for casting to another screen.
- Slideshow flow includes:
  - Game rules
  - Game scores
  - Overall standings
- Presenter and display stay in sync in real time (same browser profile).

## Quick start

1. Open `index.html` in Safari/Chrome.
2. Enter players and games.
3. Tap **Open Display** and cast that tab/screen.
4. Use **Next/Previous** on presenter to control slides.
5. Keep editing scores while presenting.

## iPad tips

- Add to Home Screen for full-screen app behavior.
- Keep presenter on iPad and cast display window through AirPlay/HDMI.
- Use larger text scaling in iPad settings if needed.
